---
description: Какие инструменты XLI доступны в этом сеансе
allowed-tools: Bash(xli:*)
---

Покажи список инструментов XLI и проверь, что MCP-сервер отвечает:

```bash
xli mcp list
```

Для каждого включённого сервера скажи одной строкой, зачем он нужен. Отдельно
отметь `xli` — это инструменты самого XLI, доступные тебе как MCP.
