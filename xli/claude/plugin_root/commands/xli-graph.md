Покажи граф зависимостей для `$ARGUMENTS` (пусто — обзор проекта):

```bash
xli graph $ARGUMENTS
```

Объясни по-русски: какие модули самые связанные, где циклы, что сломается при
правке. Если в графе есть цикл — назови его и предложи, как разорвать.
