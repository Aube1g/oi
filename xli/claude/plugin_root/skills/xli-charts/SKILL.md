# Графики в терминале

Когда в задаче есть числа, которые надо показать (время сборки, размеры файлов,
распределение, динамика), не рисуйте ASCII-картинку вручную — вызовите
инструмент `chart` MCP-сервера `xli`.

Он принимает вид графика и данные, возвращает готовый текст:

| Вид | Когда |
| --- | --- |
| `bar` | сравнить несколько значений (кто дольше) |
| `line` | временной ряд |
| `spark` | одна строка динамики |
| `hist` | распределение |
| `timeline` | этапы во времени |
| `stacked` | доли одного целого |
| `tree` | вложенность (файлы, зависимости) |
| `heat` | матрица (день × час, модуль × модуль) |
| `treemap` | размеры вложенных частей |
| `table` | числа, которые надо прочитать точно |
| `gauge` | одно значение в процентах |

Правила: числа в подписях — по-русски (`2,3 млн`, запятая как разделитель),
подписи из данных, без эмодзи. График должен читаться при 80 колонках.
