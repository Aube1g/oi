# Диагностика

## Сначала — доктор

```bash
xli doctor
```

Проверяет конфиг, провайдера, ключ, скиллы, MCP, ядро — и говорит, что чинить.

## Типичные ошибки провайдера

xli не показывает сырой JSON шлюза, а переводит его в одну строку:

- «провайдер молчал N с» — тайм-аут; просто повторите.
- «у провайдера кончились кредиты» — 402 / insufficient balance.
- «провайдер не принял API-ключ» — проверьте ключ в `xli config` и окружении.
- «ограничил запросы» — 429, подождите.

## Агент ответил JSON'ом вместо действия

Не ответит: парсер выцепляет нетегнутый `{"name": …, "args": …}` из текста и
исполняет как вызов инструмента, удаляя болванку из ответа. Если вы видите
в ответе JSON — сообщите об этом как о баге.

## XLI_CONFIG_DIR

Тесты и изолированные запуски используют свой каталог конфига; если «config
ведёт себя странно», проверьте `env | grep XLI`.

## Логи сессии

```bash
xli session list
xli session show <id> --json
```
