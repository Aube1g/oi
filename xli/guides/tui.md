# TUI — полноэкранный интерфейс

## Запуск

```bash
xli tui
xli tui продолжай с того места   # сразу с задачей
```

## Что на экране

- Сверху — история сессии (прошлые сообщения подгружаются при старте).
- Размышления модели (`think`) — витиеватая строка с `∴`.
- Вызовы инструментов — одной строкой: `read path 340:20`, без JSON.
- Снизу — поле ввода с подсказкой и статус: шаги, инструменты, ошибки, токены.

## Клавиши

- `Enter` — отправить, `↑` — прошлая задача, `^L` — перерисовать, `^C` — выход.
- На запросе подтверждения: `y` — разрешить, `n` — отказать, `a` — всё.

## Слеш-команды

`/help`, `/tools`, `/skills`, `/mode …`, `/model …`, `/session`, `/clear`.
Многострочный ввод: `Ctrl+J` — новая строка в поле.

## Если терминал маленький

TUI нужно минимум 20 колонок и 8 строк — иначе он честно скажет об этом,
а не развалится.
