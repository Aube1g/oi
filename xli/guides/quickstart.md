# Быстрый старт

## Первая задача

```bash
xli run "прочитай README.md и сделай короткое резюме"
```

Агент читает файлы сам — не надо их вставлять в запрос.

## Три способа работать

- `xli run "…"` — один запуск, ответ в терминал.
- `xli` (без аргументов) — REPL: диалог со слеш-командами (`/help`).
- `xli tui` — полноэкранный интерфейс с историей сессии и подтверждениями.

## Провайдер и ключ

```bash
xli config set provider openai
xli config set provider.model openai/gpt-5.6-terra
export OPENAI_API_KEY="sk-…"
```

Проверка связи без траты токенов: `xli doctor`.

## Подтверждения

По умолчанию пишущие инструменты спрашивают разрешения. Режимы:
`auto` (не спрашивать), `confirm` (спрашивать), `readonly` (только читать).

```bash
xli run --mode confirm "исправь опечатки в src/main.py"
```
