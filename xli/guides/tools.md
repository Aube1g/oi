# Инструменты агента

## Что агент умеет из коробки

```bash
xli tools           # живой список из реестра
```

- `read` / `write` / `edit` — файлы (edit — точечная замена строки).
- `ls` / `glob` / `grep` — навигация и поиск по проекту.
- `bash` / `git` — команды и версионирование.
- `todo` — план работ на задачу.
- `think` — рассуждение вслух. Модель использует его, чтобы разложить
  мысли по шагам перед действием; видно в выводе как курсивная строка.

## Режимы plan и build

```bash
xli run --plan "как ты отрефакторишь модуль X?"   # только чтение + план
xli run --build "сделай это"                      # все инструменты
```

`plan` не даёт пишущих инструментов вовсе — сломать ничего нельзя.

## Поиск по вызовам

В выводе CLI вызов выглядит так:

```
  -> read src/main.py
     [ok] 240 строк
```

Сырые JSON-аргументы не показываются: вместо них — человекочитаемая строка.
